# Modificateurs de taille

**Catégorie :** 07. Combat  
**Description :** Petit, Moyen, Grand ; bonus/malus de dégâts.

## Contexte

Les modificateurs de taille affectent les dégâts selon la taille de la cible : Petit (plus difficile à toucher, moins de surface), Moyen (référence), Grand (plus facile à toucher, plus de surface). Inspiré de Ragnarok Online.

**Rôle :** Équilibrage selon le type de monstre. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

| Taille cible | Modificateur dégâts | Modificateur hit |
|--------------|--------------------|------------------|
| Petit | 75–85 % | -10 % |
| Moyen | 100 % | 0 % |
| Grand | 115–125 % | +10 % |
