# Vendeurs joueur

**Catégorie :** 12. Économie et commerce  
**Description :** PNJ vendeurs gérés par un joueur ; vente hors-ligne.

## Contexte

Un joueur peut créer un PNJ vendeur (ou boutique) pour vendre ses objets. Vente possible même quand le joueur est déconnecté. Voir [vente vending](../11-inventaire-objets/vente-vending.md). Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
