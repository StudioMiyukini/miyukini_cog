# Jay1Tribu

## Communauté et Réseaux

**Jay1Tribu** est le service de gestion communautaire et sociale (tribus, groupes, échanges).

## Rôle

> Jay1Tribu **fédère** les utilisateurs en communautés souveraines.

## Fonctionnalités Principales

| Fonction | Description |
|----------|-------------|
| **Tribus** | Groupes, thèmes, membres |
| **Contenu** | Posts, commentaires, partage |
| **Modération** | MiyuSocialModeration, signalements |
| **Profils** | MiyuSocialProfile, visibilité |

## Document Conceptuel

Le positionnement et les concepts (tribu, gouvernance, limites) sont décrits dans le document conceptuel du service.
