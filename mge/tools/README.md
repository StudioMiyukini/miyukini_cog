# MGE Platform — Tooling Layer

Outils d'édition autour du Kernel MGE. Aucun outil ne modifie le runtime.

## Structure

- `data-authoring/` — SQL Editor (stats, unités, factions, loot)
- `prefab-editor/` — Création visuelle entités
- `balance-lab/` — Simulation paramètres
- `battle-sandbox/` — Mini runtime formations/LOD
- `sprite-tool/` — Assets 2D (pivot, hitbox, atlas)
- `rule-editor/` — Règles gameplay déclaratives
- `export-pipeline/` — SQL/JSON → runtime statique
- `ai-assist/` — Assistant IA sur outils
