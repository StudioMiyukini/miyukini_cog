# Poison over time (DoT poison)

**Catégorie :** 08. Dégâts, résistances et effets  
**Description :** Dégâts de poison dans le temps.

## Contexte

Le poison over time (DoT) inflige des dégâts périodiquement pendant une durée. Peut stack ou refresh. Résistible par la résistance poison. Voir [effets-statut](effets-statut.md).

**Rôle :** Dégâts différés, builds poison. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

- Tick toutes les X secondes
- Dégâts par tick : fixe ou % PV
- Durée totale ou nombre de ticks
- Stack : cumul ou refresh
