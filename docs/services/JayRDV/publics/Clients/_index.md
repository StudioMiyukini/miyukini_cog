# Public — Clients (JayRDV)

## Contexte

Les **Clients** sont le public B2C du service JayRDV : personnes qui **prennent rendez-vous** auprès des professionnels, avec ou sans compte selon le parcours (réservation guest possible).

## Portée / Scope

- **Qui** : Particuliers, patients, consommateurs qui réservent un créneau chez un professionnel (santé, bien-être, services, conseil).
- **Compte** : Compte client (optionnel ; réservation possible en guest).
- **Espace** : Espace client / Mon compte : mes RDV, historique, rappels, annulations, préférences.
