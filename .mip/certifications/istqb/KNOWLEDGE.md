## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Test principles, lifecycle and psychology | Explain why testing reduces risk not uncertainty to zero |
| M2 | Static testing and reviews | Run review checklist and defect logging |
| M3 | Black box techniques: EP, BVA, decision tables, state transitions | Design test sets from specifications |
| M4 | Test management, risk based testing and defect workflow | Prioritize tests and report quality status |

- [ ] Produce defect reports with severity and priority
- [ ] Reach target score on full ISTQB mock exams
