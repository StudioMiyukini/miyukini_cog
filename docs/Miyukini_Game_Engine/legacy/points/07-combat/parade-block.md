# Parade et block

**Catégorie :** 07. Combat  
**Description :** Parade au bouclier ; % de blocage ; contre-attaque après block.

## Contexte

La parade (block) permet de réduire ou annuler les dégâts avec un bouclier. Un % de blocage détermine la probabilité ; une contre-attaque peut suivre. Lié aux [modificateurs de taille](modificateurs-taille.md) (petit = plus difficile à bloquer).

**Rôle :** Rôle tank, valeur du bouclier. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

### % de blocage

- Vérification après hit réussi
- Réduction : 50–100 % des dégâts

### Contre-attaque

- Optionnel : après block réussi, coup immédiat
- Dégâts réduits ou normaux
