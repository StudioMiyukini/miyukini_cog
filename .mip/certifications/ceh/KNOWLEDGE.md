# CEH - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Reconnaissance, scanning and enumeration techniques | Build legal pre engagement recon workflow |
| M2 | Attack techniques across web, network and system layers | Explain exploit path and defensive controls |
| M3 | Vulnerability assessment and penetration methodology | Scope tests and prioritize findings |
| M4 | Reporting, legal boundaries and ethics | Deliver actionable and compliant reports |

- [ ] Produce finding report with reproduction and remediation
