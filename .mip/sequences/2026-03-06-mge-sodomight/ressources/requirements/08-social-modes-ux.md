# 08 - Social, modes, UX

## Modes de jeu

- solo offline
- coop online host-authoritative
- ladder / saison
- hardcore
- trade
- PvP limite

## Social minimum

- lobby de partie
- chat texte
- echange direct
- liste amis et invites via Central plus tard
- telemetrie de version pour verifier compatibilite

## Specifique Hardcore

- mort permanente
- stockage des cadavres / memorialisation
- UX sans ambiguite au moment de la creation

## UX fondamentale

- creation perso tres rapide
- skill bar souris + clavier
- inventory grid
- stash
- vendor window
- quest log
- automap
- options audio/video/input

## Accessibilite moderne a ajouter

- remap complet
- options taille UI
- mode contrastes renforce
- options flash / shake
- tooltips persistants
- journal d'erreurs pour crash ou save corrompue

## Relation avec Central

- installation, mise a jour et lancement depuis Central
- eventuellement affichage d'une fiche service et d'un statut de version
- possibilite de lier Sodomight a l'identite Central si une composante online est activee

## Exigences moteur

- couche UI separee du runtime
- input rebinding data-driven
- localisation future possible
- wrappers pour overlays Central si necessaire
