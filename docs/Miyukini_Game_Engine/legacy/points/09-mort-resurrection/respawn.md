# Respawn

**Catégorie :** 09. Mort et résurrection  
**Description :** Lieu de réapparition ; run back.

## Contexte

Le respawn définit où le joueur réapparaît après la mort : [cimetière](cimetiere-point-reapparition.md), point de sauvegarde, ou run back au [corps](corps-corpse.md). Voir [résurrection](resurrection.md) pour les options alternatives.

**Rôle :** Pénalité de mort, flow. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

- Spawn au cimetière le plus proche
- Ou réapparition au corps (si récupération)
- Run back : déplacement à pied jusqu'au corps
