# MiyuTreasury — Référence des outils

## 1. Contexte

Ce document décrit **chaque outil (Tool)** composant le kit MiyuTreasury. Référence technique des capacités atomiques de trésorerie et prévisionnel. Données = KindMother (lecture). Règles alertes = StrongFather.

**Référence du kit :** [MiyuTreasury - Documentation Fondatrice](./MiyuTreasury%20-%20Documentation%20Fondatrice.md)

|--------|-------------|--------|------------------|
