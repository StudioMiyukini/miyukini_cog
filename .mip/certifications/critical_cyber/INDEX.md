# Critical Cyber Certifications - Index

> Parcours IA pour verifier des controles de conformite sur certifications cyber critiques.

## Parcours de formation IA

1. Charger PATHWAY.md.
2. Choisir la certification cible dans `../<cert>/critical_kb/INDEX.md`.
3. Ouvrir le fichier connaissance atomique de la condition a verifier.
4. Appliquer la table Verification de controle et statuer Conforme/Partiel/Non conforme.
