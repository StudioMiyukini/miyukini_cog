# Morale des troupes

**Catégorie :** 14. Siège et territoire  
**Description :** Dépend du combat ; fuite ; renforcement.

## Contexte

Morale des troupes (NPC, mercenaires) : varie selon les victoires/défaites. Faible morale : fuite, désertion. Renforcement via victoires ou compétences. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
