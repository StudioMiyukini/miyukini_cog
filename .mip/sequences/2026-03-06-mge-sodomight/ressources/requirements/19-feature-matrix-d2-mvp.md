# 19 - Feature matrix D2 -> MVP Sodomight

## Couverture fonctionnelle cible

### Personnage et progression

- creation personnage : requis MVP
- classes multiples : requis MVP
- 3 trees par classe : requis MVP
- level up : requis MVP
- points de stats : requis MVP
- points de skills : requis MVP
- respec encadre : requis MVP si la cible D2 retenue l'exige

### Combat

- melee : requis MVP
- ranged : requis MVP
- cast elementaire : requis MVP
- buffs / debuffs : requis MVP
- summons / traps selon classes retenues : requis MVP
- hit recovery / breakpoints : requis MVP

### Items

- normal / magic / rare / unique / set : requis MVP
- sockets : requis MVP
- gemmes / runes / joyaux equivalents : requis MVP
- runewords equivalents : requis MVP
- charms equivalents : requis MVP
- cube recipes : requis MVP

### Ville

- stash : requis MVP
- vendors : requis MVP
- identify / repair : requis MVP
- gamble : requis MVP
- resurrect merc : requis MVP

### Monde

- zones randomisees : requis MVP
- quetes de progression : requis MVP
- waypoints : requis MVP
- town portal : requis MVP
- camp de depart : requis MVP
- Acte 1 complet : requis MVP

### Meta

- saves : requis MVP
- hardcore : requis MVP
- party/co-op : requis MVP
- pvp : requis MVP
- ladder runtime / ranking / contrats : requis MVP
- service live saisonnier complet : hors MVP de contenu/exploitation
- actes 2 a 5 comme contenu authored : hors MVP
- endgame additionnel : hors MVP contenu

## Regle de priorisation

Si une feature existe dans D2, elle doit etre couverte dans le MVP au minimum par runtime, donnees, UI, tests ou harness. Seul le contenu authored hors camp + Acte 1 et l'exploitation live complete peuvent rester hors MVP.
