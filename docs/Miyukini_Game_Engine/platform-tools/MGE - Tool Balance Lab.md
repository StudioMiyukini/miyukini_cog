# MGE — Tool Balance Lab

## Contexte

Outil de simulation des paramètres de jeu sans lancer le jeu complet. Critique pour Allumina : courbes XP, scaling, économie, comparaison factions.

## Portée / Scope

- **Applicable à :** Équilibrage Allumina, tuning gameplay.
- **Statut :** Spécification.

---

## Rôle

Simuler des paramètres sans lancer le jeu complet.

## Permet

- Tester courbes XP
- Tester scaling exponentiel
- Simuler combats statistiques
- Tester économie (ressources, coûts)
- Comparer 2 factions

## Sortie

- Graphiques (courbes, tendances)
- CSV export
- Recommandations IA (optionnel)

## Règles

- Simulation pure (pas de rendu obligatoire)
- Peut consommer données Data Authoring
- Résultats exportables vers Export Pipeline ou Balance Lab interne
