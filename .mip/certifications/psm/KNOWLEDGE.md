# PSM - Knowledge Requirements

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Scrum theory: empiricism and values | Explain transparency, inspection, adaptation in practice |
| M2 | Accountabilities: Product Owner, Scrum Master, Developers | Resolve role boundaries on concrete cases |
| M3 | Events and artifacts with commitments | Build a Sprint Goal, Product Goal and Definition of Done |
| M4 | Facilitation and anti patterns | Run planning, review and retrospective with clear outcomes |
