# JayXpose

## Portfolio et Présence Professionnelle

**JayXpose** est le service de gestion de portfolio et de présence professionnelle. Il permet de créer, organiser et présenter un portfolio (projets, réalisations, documents professionnels).

## Rôle

> JayXpose **expose** votre travail de manière structurée et contrôlée.

## Fonctionnalités Principales

| Fonction | Description |
|----------|-------------|
| **Portfolio** | Projets, réalisations, médias |
| **Documents professionnels** | CV, attestations, coffre-fort |
| **Page Builder** | Mise en page et présentation |
| **Intégration** | Sync avec MiyukiniPoS, Central, JayFestival |

## Données et Sécurité

- Données stockées localement (KindMother)
- Niveaux de confidentialité et partage inter-services documentés
- Intégration possible avec JayKonta (facturation, clients)

## Architecture

- **Persistance** : Schéma KindMother, base SQLite/SQLCipher
- **UI** : Composants JayKoa, refonte page builder
- **Interfaces** : Spécifications inter-services (Central, JayFestival)
