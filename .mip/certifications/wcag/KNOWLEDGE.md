# WCAG 2.2 - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Lise
**Validation type** : Audit accessibilite

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | POUR principles and conformance levels | Classify criteria by A, AA, AAA relevance |
| M2 | AA criteria for keyboard, focus, contrast and forms | Validate interactions without mouse |
| M3 | Semantics, ARIA, accessible name and role mapping | Ensure assistive tech can parse UI |
| M4 | Accessibility audit workflow and remediation | Prioritize blockers and verify fixes |

## Pre-certification Validation

- [ ] Complete keyboard only walkthrough on critical journeys
- [ ] Deliver contrast and focus compliance evidence
- [ ] Produce accessibility report with remediation plan
