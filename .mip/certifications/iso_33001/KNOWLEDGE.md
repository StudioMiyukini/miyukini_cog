# ISO 33001 - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Arianne
**Validation type** : Evaluation de maturite

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Process capability and maturity concepts | Distinguish capability levels and maturity levels |
| M2 | Process assessment indicators and evidence | Build evidence matrix per process |
| M3 | Rating method and assessor discipline | Apply consistent scoring rules |
| M4 | Improvement roadmap from assessment outcomes | Prioritize improvements by value and risk |

## Pre-certification Validation

- [ ] Produce one assessed process profile
- [ ] Document objective evidence for each rating
- [ ] Build actionable improvement roadmap
