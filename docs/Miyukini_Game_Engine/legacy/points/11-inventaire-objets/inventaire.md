# Inventaire

**Catégorie :** 11. Inventaire et objets  
**Description :** Slots + poids max ; pas de drag and drop ; empilable ; tri.

## Contexte

L'inventaire du personnage stocke les objets en slots fixes. Pas de drag and drop selon le design (clic pour déplacer). Objets empilables (stack). Tri manuel ou automatique. Persistance KindMother. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

- Slots : grille fixe (ex. 8x6 = 48 slots)
- Poids max : voir [poids-encumbrance](poids-encumbrance.md)
- Empilable : même type, voir [limite-stack](limite-stack.md)
- Tri : par type, rareté, niveau
