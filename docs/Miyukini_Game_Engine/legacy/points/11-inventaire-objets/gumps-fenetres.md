# Gumps / fenêtres

**Catégorie :** 11. Inventaire et objets  
**Description :** Fenêtres/dialogs réutilisables ; sérialisables pour le réseau.

## Contexte

Les gumps (fenêtres UI type Ultima) sont des dialogs réutilisables, sérialisables pour la synchronisation réseau. Inventaire, coffres, crafting.

**Rôle :** UI cohérente, réseau. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
