# Prompt Engineering - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Jean
**Validation type** : Competence pratique

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Task framing, constraints and acceptance criteria | Produce prompts with explicit success criteria |
| M2 | Context compression and retrieval strategy | Keep high signal context within budget |
| M3 | Structured outputs and evaluation prompts | Enforce machine readable reliable outputs |
| M4 | Safety, refusal handling and fallback logic | Reduce harmful or low quality generations |

## Pre-certification Validation

- [ ] Create reusable prompt templates by task type
- [ ] Run evaluation set with pass fail thresholds
- [ ] Report token usage versus output quality
