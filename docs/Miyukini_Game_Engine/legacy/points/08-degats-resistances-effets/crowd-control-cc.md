# Crowd control (CC)

**Catégorie :** 08. Dégâts, résistances et effets  
**Description :** Stun, root, silence, freeze, slow ; résistances.

## Contexte

Le crowd control (CC) empêche ou limite les actions de la cible : stun (aucune action), root (pas de déplacement), silence (pas de sorts), freeze, slow. Les résistances réduisent la durée ou la chance.

**Rôle :** Contrôle tactique. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

| Type CC | Effet |
|---------|-------|
| Stun | Bloque tout |
| Root | Pas de déplacement |
| Silence | Pas de sorts |
| Slow | Réduction vitesse |
| Freeze | Comme stun + peut casser |
