# Rapport final - mip-cyber-certifications-kb

> Base cyber critique construite avec granulation unitaire et index MSCM.

## Synthese

- 1 dossier critique dedie
- 7 certifications/reglementations critiques couvertes
- connaissances atomiques + matrices de verification
- sources officielles internet tracees
- routage MIP actif via `registry.json` et `load-map.json`

## Usage agent

1. Charger `critical_cyber/INDEX.md`
2. Aller sur la certification cible
3. Ouvrir le fichier connaissance de la condition a verifier
4. Appliquer la table `verification de controle`
