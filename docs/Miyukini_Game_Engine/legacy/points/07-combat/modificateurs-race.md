# Modificateurs de race

**Catégorie :** 07. Combat  
**Description :** Bonus/malus selon la race de la cible.

## Contexte

Les modificateurs de race appliquent des bonus ou malus de dégâts selon la race de la cible (Humanoïde, Démon, Bête, etc.). Permet des armes ou sorts "anti-démon", "anti-undead", etc.

**Rôle :** Diversification des builds, contenu spécialisé. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

| Race | Exemple modificateur |
|------|----------------------|
| Humanoïde | 100 % |
| Démon | +25 % (arme bénie) |
| Undead | +50 % (arme sainte) |
| Bête | 100 % |
| Boss | -20 % (résistance innée) |
