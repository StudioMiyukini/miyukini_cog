# Public cible : Organisateurs

## Présentation

Les **organisateurs** sont les structures (associations, collectivités, sociétés) qui créent et gèrent des événements ou festivals sur la plateforme JayFestival. Ils disposent d’un **compte cross-événements** : un même organisateur peut gérer **plusieurs festivals/événements**.

## En bref

- **Compte** : cross-événements (plusieurs festivals).
- **Espace** : tableau de bord, liste de toutes les éditions, dashboard par édition.
- **Livrables** : éditions, exposants, plan de salle, programme, budget, documents, services visiteur (activables).
- **Publication** : annuaire des événements, répertoire des organisateurs.
