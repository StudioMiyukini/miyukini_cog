# Charrette

**Catégorie :** 11. Inventaire et objets  
**Description :** Inventaire supplémentaire ; suit le personnage.

## Contexte

La charrette est un conteneur mobile qui suit le joueur. Inventaire supplémentaire pour la récolte (mining, lumberjacking). Peut être attaquée/volée en PvP selon les zones.

**Rôle :** Récolte, transport. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
