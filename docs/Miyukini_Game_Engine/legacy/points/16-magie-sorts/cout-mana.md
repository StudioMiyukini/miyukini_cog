# Coût en mana

**Catégorie :** 16. Magie et sorts  
**Description :** Coût par sort ; régénération.

## Contexte

Chaque sort a un coût en mana. Régénération : hors combat (rapide), en combat (lente ou nulle). Réduction de coût via équipement. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
