# Snooping

**Catégorie :** 15. Réputation et criminalité  
**Description :** Consulter le contenu du sac d'un autre.

## Contexte

Snooping : regarder le contenu de l'inventaire d'un autre joueur sans voler. Nécessaire avant un pickpocket ciblé. Peut révéler la présence (détection). Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
