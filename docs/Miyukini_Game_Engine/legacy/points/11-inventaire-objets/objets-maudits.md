# Objets maudits

**Catégorie :** 11. Inventaire et objets  
**Description :** Ne peuvent pas être droppés ; effets négatifs.

## Contexte

Les objets maudits ne peuvent pas être retirés ou droppés une fois équipés. Effets négatifs (malus stats, dégâts over time). Levée de malédiction : quête ou PNJ.

**Rôle :** Risque, tension. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
