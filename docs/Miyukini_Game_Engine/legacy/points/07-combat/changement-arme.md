# Changement d'arme

**Catégorie :** 07. Combat  
**Description :** Swap d'arme en combat ; armes secondaires.

## Contexte

Le changement d'arme (weapon swap) permet de passer d'un set d'armes à un autre en combat. Les armes secondaires peuvent être une autre arme principale ou un bouclier. Un délai ou cooldown peut s'appliquer.

**Rôle :** Diversité tactique, builds hybrides. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

### Délai de swap

- Instantané ou 0.5–1 s de canalisation
- Pendant le swap : vulnérable ou invincible ?

### Sets

- Set 1 : Épée + bouclier
- Set 2 : Arc (à distance)
