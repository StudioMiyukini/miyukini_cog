# Opérateurs et Terminologie

## Opérateurs (Strate 7)

Les **Opérateurs** sont les entités fonctionnelles visibles par l’utilisateur : ce sont les « services » (JayKoa, JayKonta, Miou, etc.). Ils sont **gouvernés** par les Cores et **n’exécutent** pas eux-mêmes — ils passent par BondingBrother et les Outils.

## Termes Clés

| Terme | Définition |
|-------|------------|
| **Opérateur** | Service de la Strate 7 ; un par domaine fonctionnel (ex. JayKonta = comptabilité). |
| **Mandat** | Périmètre d’action d’un opérateur ; défini par les Cores et les contrats. |
| **Équipe Opérateurs** | Ensemble des opérateurs d’un COG ; chacun lié à un seul environnement. |

## Flux

- **Utilisateur** → interagit avec l’**interface** d’un Opérateur.
- **Opérateur** → formule une **intention** et la soumet aux **Cores** (via BondingBrother).
- **Cores** → **décident** (TAMR, BorderGuard, KindMother, etc.).
- **BondingBrother** → **traduit** en instructions pour les **Outils**.
- **Outils** → **exécutent** (MiyuSQL, MiyuAuth, etc.).

## Terminologie Interdite / Obsolète

- **KeeperOfStorage** → utiliser **KindMother**.
- Éviter les termes qui suggèrent que les Opérateurs « possèdent » les données ou décident seuls ; la **souveraineté** reste aux Cores et au COG.
