# Slots rapides

**Catégorie :** 11. Inventaire et objets  
**Description :** Ceinture à potions ; raccourcis ; empilable.

## Contexte

Barre de raccourcis (hotbar) pour les consommables et compétences. Touches 1-0 ou F1-F10. Les potions peuvent être empilées dans les slots. Voir [indicateurs cooldown](../20-interface/indicateurs-cooldown.md).

**Rôle :** Accessibilité combat. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
