# Stockage persistant

**Catégorie :** 11. Inventaire et objets  
**Description :** Stash, coffre, stockage de guilde ; partagé.

## Contexte

Stockage persistant : stash personnel, coffres de maison, stockage de guilde. Données persistées via KindMother. Peut être partagé entre personnages (stash) ou par guilde.
