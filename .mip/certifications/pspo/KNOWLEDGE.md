# PSPO - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Fabrice
**Validation type** : Examen individuel

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Product vision, Product Goal and outcomes | Translate strategy into measurable outcomes |
| M2 | Backlog ordering by value, risk and dependencies | Prioritize with explicit rationale |
| M3 | Stakeholder management and release planning | Build a release plan with assumptions |
| M4 | Evidence based product management | Use outcome metrics instead of output metrics |

## Pre-certification Validation

- [ ] Create an ordered backlog with acceptance criteria
- [ ] Write a Product Goal and release slices
- [ ] Show decision making from product evidence
