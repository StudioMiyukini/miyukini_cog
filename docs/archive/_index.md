# Archive — Documents obsolètes ou dépréciés

## Contexte

Ce dossier contient les **documents obsolètes ou dépréciés** du projet Miyukini COG. Ils sont conservés à titre de **référence historique** et ne reflètent plus l'état actuel des décisions ou de l'implémentation.

## Structure

| Dossier | Contenu typique |
|---------|------------------|
| **ux_ui/** | Anciennes stacks UI, guides remplacés (ex. egui/eframe → Dioxus). Voir [Miyukini - Stack UI egui eframe](./ux_ui/Miyukini%20-%20Stack%20UI%20egui%20eframe.md). |
| **implementation/** | Anciens suivis d'audit, plans d'implémentation remplacés ou fusionnés. |
| **tools/** | Scripts ou procédures retirés du projet (ex. démo egui). |

## Règles

- Ne pas utiliser les documents de l'archive comme référence normative.
- Pour la doc à jour : voir `docs/` (hors archive), `docs/reference/`, `docs/miyukini-webway-system/`.
- Lors du déplacement d'un document vers l'archive, ajouter en tête du document une mention **Obsolète** / **Archivé le : YYYY-MM-DD** et le chemin d'origine.
