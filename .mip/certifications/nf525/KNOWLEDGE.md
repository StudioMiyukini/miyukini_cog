# NF525 - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Victor
**Validation type** : Certification produit ou attestation

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | ISCA criteria: inalterability, securisation, conservation, archivage | Translate criteria into system controls |
| M2 | Cash register lifecycle controls | Prevent deletion or hidden alteration of transactions |
| M3 | Fiscal evidence and closure routines | Produce mandatory records for tax inspection |
| M4 | Access control and trace logging for cashier operations | Enforce least privilege and traceability |

## Pre-certification Validation

- [ ] Demonstrate immutable ticket lifecycle
- [ ] Document closure and archive procedure
- [ ] Prepare certification or attestation evidence set
