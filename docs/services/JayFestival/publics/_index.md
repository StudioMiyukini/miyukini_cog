# Structure par public cible

La documentation du service **JayFestival** est organisée par **type de public cible** : chaque public dispose d’un dossier dédié avec une présentation (_index.md) et un ou plusieurs documents détaillant le parcours, les capacités et les limites.

## Publics cibles

| Public | Description | Documentation |
|--------|-------------|---------------|
| **Organisateurs** | Structures qui créent et gèrent des événements/festivals ; compte cross-événements (plusieurs festivals). | [Organisateurs](./Organisateurs/_index.md) |
| **Exposants** | Professionnels ou structures qui participent à des événements en tant qu’exposants ; dashboard dédié, compte cross-événements, gestion d’agenda. | [Exposants](./Exposants/_index.md) |
| **Visiteurs** | Personnes qui fréquentent les événements ; espace dédié, compte cross-événements, services activables par l’organisateur (jeux, concours, ateliers, pass VIP). | [Visiteurs](./Visiteurs/_index.md) |
| **Utilisateur non connecté** | Personnes qui consultent le catalogue sans compte ; Façade publique gouvernée (annuaire événements, répertoire organisateurs, répertoire exposants). | [Utilisateur non connecté](./UtilisateurNonConnecte/_index.md) |

## Vue d’ensemble

| Public | Compte | Espace | Accès principal |
|--------|--------|--------|-----------------|
| **Organisateurs** | Cross-événements | Tableau de bord, dashboard par édition | Éditions (multi-festivals), exposants, plan, programme, budget, documents, services visiteur |
| **Exposants** | Cross-événements | Dashboard exposant | Candidatures, participations (plusieurs festivals), agenda, documents, factures |
| **Visiteurs** | Cross-événements | Espace dédié visiteur | Agenda, billets, réservations, pass VIP, jeux, concours, ateliers |
| **Utilisateur non connecté** | Aucun | Façade publique | Catalogue en lecture seule (annuaires, recherche, fiches) |
