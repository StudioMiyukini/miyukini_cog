# JayFestival

## Organisation d'Événements et Festivals

**JayFestival** est le service dédié à l’organisation d’événements, festivals et stands (exposants, organisateurs, visiteurs).

## Rôle

> JayFestival **planifie** et **gère** les événements et les réservations de stands.

## Fonctionnalités Principales

| Fonction | Description |
|----------|-------------|
| **Plan interactif** | Carte des stands, emplacements |
| **Réservation stands** | Réservation par exposants |
| **Publics** | Exposants, organisateurs, visiteurs, non connectés |
| **UI** | Référence transcription katakana, interfaces par public |

## Données et Intégration

- Base de données et migration (Supabase → SQLite) documentées
- Intégration avec JayXpose et Central
- État des interfaces et documentation des services
