# PMP (PMBOK 7) - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Maria
**Validation type** : Examen individuel

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | PMBOK 7 principles and 8 performance domains | Explain tradeoffs on a project scenario |
| M2 | Predictive, agile and hybrid delivery approaches | Select and justify a delivery model |
| M3 | Scope, schedule, cost, risk and value tracking | Build a basic charter, WBS and risk register |
| M4 | Stakeholder engagement, governance and communication | Define governance cadence and decision logs |

## Pre-certification Validation

- [ ] Pass at least 2 full mock exams above target score
- [ ] Produce a complete project charter plus WBS and risk register
- [ ] Explain corrective actions from schedule or cost variance
