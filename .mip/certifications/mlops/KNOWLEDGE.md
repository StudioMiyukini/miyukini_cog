# MLOps - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Jean
**Validation type** : Competence pratique

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Data and model versioning for reproducibility | Rebuild training runs deterministically |
| M2 | Training validation pipeline and feature discipline | Control data leakage and model quality |
| M3 | Deployment strategies with rollback safety | Operate canary or blue green releases |
| M4 | Monitoring drift, quality, latency and cost | Trigger retraining and incident workflows |

## Pre-certification Validation

- [ ] Deliver end to end training to serving runbook
- [ ] Publish model card and governance notes
- [ ] Maintain production monitoring dashboard and alerts
