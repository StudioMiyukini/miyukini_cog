# PRINCE2 - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Maria
**Validation type** : Examen individuel

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | 7 principles and management by exception | Map each principle to a real delivery context |
| M2 | 7 themes: business case, organization, quality, plans, risk, change, progress | Produce a compact PID style summary |
| M3 | 7 processes from Starting Up to Closing | Build a stage based flow with controls |
| M4 | Tailoring PRINCE2 to project scale and risk | Define stage tolerances and escalation paths |

## Pre-certification Validation

- [ ] Prepare a stage plan with tolerances
- [ ] Write one exception report and escalation path
- [ ] Demonstrate business case updates over stages
