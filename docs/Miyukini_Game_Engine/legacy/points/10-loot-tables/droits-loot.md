# Droits de loot

**Catégorie :** 10. Loot et tables  
**Description :** Premier coup, dernier coup ; partage.

## Contexte

Les droits de loot déterminent qui peut ramasser : premier à taper (FFA), dernier coup (kill steal), ou partage (need/greed, round-robin). Essentiel pour le contenu de groupe.

**Rôle :** Équité groupe. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

| Mode | Attribution |
|------|-------------|
| FFA | Premier arrivé |
| Master looter | Chef distribue |
| Need/Greed | Roll sur objet |
| Round-robin | À tour de rôle |
