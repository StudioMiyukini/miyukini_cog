# JayXpose - Guide Coffre-Fort

## Objectif

Stocker et partager les documents professionnels de facon gouvernee.

## Etapes

1. Aller sur XP-E09.
2. Ajouter un document via XP-E10.
3. Renseigner type, expiration, notes.
4. Lancer un partage via XP-E12.

## Regles

- Partage uniquement via mandat
- Versionner en cas de remplacement
- Surveiller les expirations
