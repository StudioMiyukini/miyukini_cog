# Zone d'effet (AOE)

**Catégorie :** 07. Combat  
**Description :** Cercle, cône ; dégâts multiples ; indicateurs.

## Contexte

Les zones d'effet (AOE, Area of Effect) permettent d'affecter plusieurs cibles dans une zone : cercle, cône, ligne. Des indicateurs visuels préfigurent la zone avant l'impact.

**Rôle :** Combat tactique, groupe. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

### Formes

| Forme | Paramètres |
|-------|------------|
| Cercle | Centre, rayon |
| Cône | Origine, angle, longueur |
| Ligne | Origine, direction, largeur, longueur |

### Indicateurs

- Affichage avant cast (zone rouge/verte)
- Amis vs ennemis : couleurs différentes
