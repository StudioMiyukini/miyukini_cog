# FinOps - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Jean
**Validation type** : Pratique organisationnelle

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Cost visibility, tagging and allocation | Build chargeback or showback views |
| M2 | Unit economics and KPI design | Track cost per service or capability |
| M3 | Optimization levers: rightsizing and commitments | Prioritize actions by impact and risk |
| M4 | Governance cadence and accountability model | Run recurring optimization ceremonies |

## Pre-certification Validation

- [ ] Produce monthly cost review with owners
- [ ] Maintain optimization backlog with expected savings
- [ ] Configure anomaly detection and response workflow
