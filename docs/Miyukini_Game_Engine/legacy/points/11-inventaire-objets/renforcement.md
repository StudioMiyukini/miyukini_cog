# Renforcement

**Catégorie :** 11. Inventaire et objets  
**Description :** Enchantement / raffinement (+N) ; risque d'échec ; over-upgrade.

## Contexte

Renforcement : améliorer un objet (+1, +2...) avec risque d'échec (perte ou destruction). Over-upgrade : au-delà d'un seuil, risques accrus. Lié aux [affixes](affixes.md).

**Rôle :** Progression d'objet, économie. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
