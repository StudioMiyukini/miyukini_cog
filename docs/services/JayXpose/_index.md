# JayXpose - Identite professionnelle exposant, vitrine et coffre-fort

## Contexte

JayXpose est le service Miyukini dedie a l'identite professionnelle exposant:
- profil entreprise
- catalogue produits
- page builder vitrine
- coffre-fort documentaire
- annuaire et integrations inter-services
