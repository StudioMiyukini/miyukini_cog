# JayXpose - Guide Page Builder

## But

Construire une page presentation avec le builder M3.

## Workflow

1. Aller sur XP-E07.
2. Choisir un bloc dans la librairie.
3. Inserer le bloc dans le canvas.
4. Reordonner les blocs.
5. Verifier le JSON document.
6. Enregistrer puis previsualiser (XP-E08).

## Blocs MVP

- hero
- features
- product_grid
- story
- testimonials
- faq
- contact_cta
- gallery

## Bonnes pratiques

- 1 hero court
- 3 features max
- 1 grille produits
- 1 CTA final
