# Éléments

**Catégorie :** 08. Dégâts, résistances et effets  
**Description :** Feu, Eau, Vent, Terre, Saint, Obscur, Neutre.

## Contexte

Les éléments définissent le type des dégâts et des sorts. Des relations de force/faiblesse (ex. Feu > Vent > Terre > Eau > Feu) peuvent exister. Lié aux [résistances](resistances.md) et [immunités](immunites.md).

**Rôle :** Système de type, variété des sorts. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

### Éléments standard

| Élément | Faiblesse typique |
|---------|-------------------|
| Feu | Eau |
| Eau | Terre/Éclair |
| Vent | Feu |
| Terre | Vent |
| Saint | Obscur |
| Obscur | Saint |
| Neutre | Aucune |
