# CKA - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Hugo
**Validation type** : Examen pratique

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Kubernetes cluster architecture and control plane | Explain component roles and failure impact |
| M2 | Workloads lifecycle and troubleshooting | Operate deployments, rollouts and diagnostics |
| M3 | Networking, services, ingress and policies | Expose workloads securely and predictably |
| M4 | Storage, RBAC and backup operations | Protect data and recover cluster state |

## Pre-certification Validation

- [ ] Complete timed kubectl task drills
- [ ] Run etcd backup and restore exercise
- [ ] Apply RBAC and network policy hardening checks
