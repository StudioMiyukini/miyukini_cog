# Rôles (Tank, DPS, soigneur)

**Catégorie :** 07. Combat  
**Description :** Tank, DPS, soigneur ; synergies.

## Contexte

Les rôles définissent les archetypes de groupe : Tank (absorber les dégâts, tenir l'aggro), DPS (dégâts), Soigneur (heal). Les synergies entre rôles sont essentielles au combat de groupe. Voir [aggro-menace](aggro-menace.md) et [officiers-alliés](officiers-allies.md).

**Rôle :** Design de groupe, équilibrage. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

| Rôle | Rôle principal | Stats clés |
|------|----------------|------------|
| Tank | Tenir l'aggro, survivre | VIT, DEF, menace |
| DPS | Maximiser les dégâts | ATK, critique |
| Soigneur | Maintenir le groupe en vie | INT, heal power |
