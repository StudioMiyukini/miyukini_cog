# Zones PK

**Catégorie :** 15. Réputation et criminalité  
**Description :** Zones où le PvP est autorisé ; zones sûres.

## Contexte

Zones PK : PvP autorisé, pas de pénalité pour tuer. Zones sûres : pas de PvP. Voir [zones PvP](../18-logement-monde/zones-pvp.md) et [zones sûres](../18-logement-monde/zones-sures.md). Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
