# Cimetière et point de réapparition

**Catégorie :** 09. Mort et résurrection  
**Description :** Lieu de respawn.

## Contexte

Le cimetière est le point de réapparition par défaut après la mort. Le joueur peut définir un point de réapparition personnalisé (inn, ville). Voir [respawn](respawn.md).

**Rôle :** Spawn par défaut. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).

---

## Spécifications techniques

- Un cimetière par zone ou plusieurs
- Point de réapparition : interaction avec PNJ ou objet (lit)
