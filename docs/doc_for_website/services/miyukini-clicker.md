# Miyukini Clicker

## Jeu Clicker Intégré

**MiyukiniClicker** est un jeu de type clicker intégré à l’écosystème (ville, construction, mécaniques de progression).

## Rôle

> MiyukiniClicker **offre** une expérience ludique et gamifiée au sein du COG.

## Fonctionnalités Principales

| Fonction | Description |
|----------|-------------|
| **Zone Cité** | Construction, bâtiments, ressources |
| **Mécaniques** | Clicker, blocs organiques, molécules (layout) |
| **MVP** | Écrans et mécaniques minimales |
| **Parcours utilisateur** | Tutoriel, progression |
