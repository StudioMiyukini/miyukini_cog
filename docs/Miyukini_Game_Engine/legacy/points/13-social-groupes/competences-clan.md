# Compétences de clan

**Catégorie :** 13. Social et groupes  
**Description :** Skills financées par la clan ; effets de groupe.

## Contexte

Compétences de clan : améliorations achetées par la guilde (or collectif), effets pour tous les membres. Ex : bonus XP, téléportation. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
