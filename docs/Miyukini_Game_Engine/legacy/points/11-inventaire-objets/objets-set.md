# Objets Set

**Catégorie :** 11. Inventaire et objets  
**Description :** Pièces d'ensemble ; bonus pour 2, 3, 5+ pièces.

## Contexte

Les sets sont des ensembles d'objets portant le même nom. Bonus cumulatifs selon le nombre de pièces équipées (2, 3, 5, etc.). Incite à collecter.

**Rôle :** Builds, collection. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
