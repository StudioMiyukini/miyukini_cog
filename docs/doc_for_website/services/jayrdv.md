# JayRDV

## Gestion de Rendez-vous et Planification

**JayRDV** est le service de prise de rendez-vous et de planification (clients, professionnels).

## Rôle

> JayRDV **planifie** les rendez-vous et **gère** les créneaux.

## Fonctionnalités Principales

| Fonction | Description |
|----------|-------------|
| **Créneaux** | Disponibilités, réservation |
| **Publics** | Clients, professionnels, utilisateur non connecté |
| **Calendrier** | Vue calendrier, rappels |

## Document Fondateur

Le service est défini par un document fondateur ; les parcours détaillés (clients, professionnels) sont documentés dans les publics dédiés.
