# Menus contextuels

**Catégorie :** 11. Inventaire et objets  
**Description :** Clic droit ; actions selon le type d'objet.

## Contexte

Le clic droit sur un objet ouvre un menu contextuel : utiliser, équiper, vendre, jeter, etc. Actions varient selon le type (équipement, consommable, quest item).

**Rôle :** UX inventaire. Voir [MGE - Référence technique](../MGE%20-%20Miyukini%20Game%20Engine%20-%20Reference%20Technique.md).
