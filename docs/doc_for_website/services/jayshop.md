# JayShop

## Boutique et Commerce en Ligne

**JayShop** est le service de boutique et de commerce en ligne intégré à l’écosystème Miyukini.

## Rôle

> JayShop **gère** le catalogue, le panier et les ventes en ligne.

## Fonctionnalités Principales

| Fonction | Description |
|----------|-------------|
| **Catalogue** | Produits, catégories, prix |
| **Panier** | Ajout, modification, suppression |
| **Checkout** | Paiement, livraison (selon implémentation) |
| **Interfaces** | Inter-services (JayKonta, Central, etc.) |
