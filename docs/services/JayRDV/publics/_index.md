# Structure par public cible — JayRDV

La documentation du service **JayRDV** est organisée par **type de public cible** : chaque public dispose d’un dossier dédié avec une présentation (_index.md) et des documents détaillant les besoins, le parcours, les capacités et les livrables.

## Publics cibles

| Public | Description | Documentation |
|--------|-------------|---------------|
| **Professionnels** | Praticiens, entreprises ou équipes qui proposent des créneaux de réservation ; gestion des plannings, des ressources et des RDV. | [Professionnels](./Professionnels/_index.md) |
| **Clients** | Personnes qui prennent rendez-vous (B2C) ; compte client, historique des RDV, rappels, annulations. | [Clients](./Clients/_index.md) |
| **Utilisateur non connecté** | Personnes qui consultent ou réservent sans compte ; Façade publique gouvernée (liens de réservation, widget, parcours guest). | [Utilisateur non connecté](./UtilisateurNonConnecte/_index.md) |

## Vue d’ensemble

| Public | Compte | Espace | Accès principal |
|--------|--------|--------|------------------|
| **Professionnels** | Compte pro (mono ou multi-établissement) | Tableau de bord pro, calendrier centralisé | Plannings, services, ressources, RDV, notifications, stats, intégrations |
| **Clients** | Compte client (optionnel selon parcours) | Espace client / Mon compte | Mes RDV, historique, rappels, annulations, préférences |
| **Utilisateur non connecté** | Aucun (ou parcours guest) | Façade publique | Prise de RDV via lien ou widget, sans création de compte obligatoire |
