Miyukini Cloud

Installer l'application sur votre appareil

iPhone / iPad (iOS)

  1. Ouvrez Safari (obligatoire, pas Chrome)
  2. Allez sur cloud.miyukini-home.org
  3. Appuyez sur le bouton Partager
  4. Choisissez "Sur l'écran d'accueil"
  5. Appuyez Ajouter — l'app apparaît sur votre écran

Android

  1. Ouvrez Chrome
  2. Allez sur cloud.miyukini-home.org
  3. Chrome affiche une bannière "Installer" en bas
  4. Ou appuyez ⋮ → "Installer l'application"
  5. L'app MiyuCloud apparaît dans vos applications

Windows / Mac / Linux

  1. Ouvrez Chrome ou Edge
  2. Allez sur cloud.miyukini-home.org
  3. Cliquez l'icône Installer dans la barre d'adresse
  4. L'app s'ouvre comme une fenêtre native
