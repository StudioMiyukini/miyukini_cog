# Spec technique - mip-cyber-certifications-kb

> Base documentaire orientee controle: condition -> preuve -> methode de verification -> decision.

## Architecture

- Dossier cible: `.mip/certifications/critical_cyber/`
- Granularite: 1 fichier = 1 connaissance verifiable
- Indexation: commentaires MSCM + `MSCM_INDEX.json`
- Parcours: progression IA generaliste -> specialiste tache

## Contrat de chaque fichier connaissance

- Contexte de la condition
- Conditions d obtention / maintien
- Table de verification de controle
- Preuves attendues
- Pratiques de preparation
- Sources officielles
