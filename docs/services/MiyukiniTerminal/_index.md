# MiyukiniTerminal — Documentation

## Contexte

**MiyukiniTerminal** est l'App Android permettant aux utilisateurs en mobilité d'interagir avec leur environnement COG via un **terminal léger** (COG de type TERMINAL, `os_type` ANDROID). Elle est enfant d'un COG STABLE du même utilisateur.
