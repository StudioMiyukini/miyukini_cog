# Lean Startup - Knowledge Requirements

> TL;DR: This file lists the concrete knowledge and evidence expected before claiming readiness for this certification.

**Owner MIP** : Fabrice
**Validation type** : Pratique methodologique

## Required Knowledge Blocks

| Block | Knowledge to master | Expected proof |
|-------|---------------------|----------------|
| M1 | Hypothesis driven product discovery | Define riskiest assumptions first |
| M2 | MVP design for fast learning | Build smallest experiment per hypothesis |
| M3 | Actionable metrics and cohort reading | Avoid vanity metrics and track behavior change |
| M4 | Pivot or persevere decisions | Set decision thresholds before running experiments |

## Pre-certification Validation

- [ ] Document at least 2 experiments with thresholds
- [ ] Maintain a learning backlog and decisions
- [ ] Show pivot or persevere decision from evidence
